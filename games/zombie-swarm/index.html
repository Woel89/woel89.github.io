Выживание под натиском волн нежити — вид сверху, авто-стрельба, нарастающее безумие. Ты двигаешься, персонаж стреляет сам: задача — не дать толпе зомби тебя окружить. Между волнами выбираешь улучшения: новые способности, прокачку урона, скорость. С каждой волной врагов становится больше и быстрее. Жанр «survivors / horde survival» — один из самых популярных в инди-играх последних лет, и теперь доступен в браузере без установки. Управление на ПК — WASD, мышь задаёт направление; на мобильном — виртуальный джойстик с авто-огнём. Играть в Zombie Swarm онлайн бесплатно.
